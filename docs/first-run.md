# DebStart

Пошаговая инструкция для первого VPS

## 01 Подключись к серверу

Мастер настроит SSH и установит выбранные компоненты. В примере ты управляешь сервером из Windows через PowerShell. На macOS и Linux подойдёт «Терминал».

### Что подготовить

- **Сервер** с Debian 12 или 13 либо Ubuntu 22.04, 24.04 или 26.04 LTS.
- **Пакеты на сервере** - `unzip` для архива, `openssh-server` и `iproute2` для SSH, `sudo` для администратора.
- **Данные от хостинга** - IP-адрес, SSH-порт, исходный логин и пароль либо ключ.
- **Архив** `debian-start.zip`. Сохрани его на компьютере, например в «Загрузки».

### НА КОМПЬЮТЕРЕ

Открой PowerShell. В примере адрес сервера - `203.0.113.10`, порт - `22`, исходный логин - `root`. Подставь свои данные от хостинга.

```powershell
ssh -p 22 root@203.0.113.10
```

При первом подключении SSH покажет отпечаток ключа сервера. Сверь его с отпечатком в панели или консоли хостинга и затем подтверди подключение. Если нужен пароль, введи его и нажми Enter. Терминал скрывает символы при вводе.

Если хостинг выдал файл ключа, добавь `-i "путь к файлу"` сразу после `ssh` и `scp`.

> [!TIP]
> Оставь это окно открытым. После входа команды в нём выполняются уже на сервере.

## 02 Загрузи архив и запусти мастер

### НА КОМПЬЮТЕРЕ

Открой **второе** окно PowerShell. Перейди в папку, куда скачал архив, и отправь файл на сервер. Подставь те же адрес, порт и логин.

```powershell
cd "$env:USERPROFILE\Downloads"
scp -P 22 ".\debian-start.zip" root@203.0.113.10:
```

На macOS и Linux перейди в папку с архивом и в команде `scp` используй `./debian-start.zip`. Двоеточие в конце команды отправляет файл в домашнюю папку пользователя на сервере.

### НА СЕРВЕРЕ

Вернись в первое окно. Если подключился как `root`, выполни эти команды по очереди.

```bash
unzip debian-start.zip
cd debian-start
bash bootstrap.sh
```

Если вошёл под другой учёткой с правами `sudo`, используй этот вариант.

```bash
unzip debian-start.zip
cd debian-start
sudo bash bootstrap.sh
```

> [!NOTE]
> Если нет `unzip`, установи его через `apt-get` перед распаковкой. Запусти мастер из распакованной папки.

## 03 Настрой сервер

В поле **Какие этапы пропустить?** введи номера из меню. `1 3 7` пропускает этапы 1, 3 и 7, а `1-3 7` пропускает этапы с 1 по 3 и этап 7. Пустой ввод включает все этапы в план. Проверь план и нажми **Запустить**. В текстовом меню введи `д`.

| Этап | Что делать |
|---|---|
| Пароль root | Введи новый пароль дважды. |
| Пользователь и SSH | Создание учётки с `sudo` и доступ SSH выбираются отдельно. Этап доступа включает keepalive для новых сеансов. |
| Имя хоста | Введи имя, например `server`. |
| Порт SSH | Введи только новый порт, например `2233`. При необходимости открой его в firewall хостинга. |
| Компоненты | Выбери пакеты APT, оболочку, Python, Docker и 3x-ui в общем меню. |

### КОМПОНЕНТЫ DOCKER

| Компонент | Для чего |
|---|---|
| **3x-ui** | Веб-панель для Xray. Новая установка использует образ `v3.3.1`. |
| **dry** | Просмотр контейнеров Docker в терминале. Дополнительная утилита. |

Мастер сам проверяет ответ SSH на сервере. Если применение настроек завершилось ошибкой, он восстанавливает текущий шаг. Доступ извне зависит от правил сети и firewall хостинга.

> [!NOTE]
> Для нового Ed25519 мастер попросит парольную фразу и покажет команду `scp`. Скачай ключ через текущий вход до применения правила SSH.

## 04 Войди под новой учёткой

Если устанавливал Oh My Zsh, мастер откроет Zsh под настроенной учёткой после завершения. Команда `exit` вернёт в предыдущую оболочку.

### НА КОМПЬЮТЕРЕ

Открой ещё одно окно терминала и выполни команду входа из итогов мастера. Если выбрал пароль, используй пароль Linux.

### НА СЕРВЕРЕ

После входа проверь права администратора и версию Python.

```bash
sudo -v
python3 --version
```

Если вход прошёл и `sudo -v` выполнилась, можно закрыть исходную SSH-сессию.

### ОТКРОЙ ПАНЕЛЬ В БРАУЗЕРЕ

Для **3x-ui** сохрани реквизиты из карточки. Открой показанный SSH-туннель в **новом окне на компьютере**. Используй порт из итогов.

```powershell
ssh -p 2233 -N -L 2053:127.0.0.1:2053 ops@203.0.113.10
```

Оставь окно туннеля открытым и введи полный URL 3x-ui в браузере. Используй отдельный логин и пароль панели.

> [!TIP]
> Для обычного входа на сервер используй пароль Linux или ключ. В браузере вводи отдельный пароль панели.

## 05 Если что-то пошло не так

| Что видишь | Что сделать |
|---|---|
| Windows не находит `ssh` или `scp` | Установи **Клиент OpenSSH** в «Дополнительных компонентах» Windows и открой PowerShell заново. |
| SSH не подключается | Проверь IP, порт, исходный логин и состояние VPS в кабинете хостинга. Если SSH недоступен, воспользуйся консолью VPS у хостинга. |
| Вход root по SSH | Если выбрал **Доступ SSH**, подключайся под выбранной учёткой. Для команд администратора используй `sudo`. |
| `Permission denied` | Проверь, под какой учёткой входишь. Для исходного входа нужны данные хостинга, для новой учётки - выбранный в мастере пароль или ключ. |
| 3x-ui не открывается | Проверь порт в итогах, окно SSH-туннеля и полный URL с путём после порта. |
| Мастер показал ошибку | Запомни название этапа и посмотри последние строки журнала на сервере. |
| «APT занят» | Дождись фонового обновления. Мастер продолжит автоматически. |
| `Stopped` и вернулся ввод команд | В том же окне введи `jobs`. Если мастер есть в списке остановленных задач, возобнови его командой `fg`. |

### НА СЕРВЕРЕ

```bash
sudo tail -n 50 /var/log/debian-start.log
```

Под `root` выполни эту команду без `sudo`. Если обращаешься за помощью, отправь название этапа и текст ошибки. Проверь, что в присланном фрагменте нет паролей и ключей.

После устранения ошибки снова запусти мастер из папки с `bootstrap.sh`. Для уже созданных панелей он использует их сохранённые каталоги данных.
